# Movie Watchlist Organizer

A simple Java Swing-based desktop application for managing a personal movie watchlist.

The project demonstrates the use of Java Collections such as `ArrayList`, `HashSet`, and `TreeSet`, along with sorting, adding, deleting, displaying, and organizing movie titles.

## Project Overview

Movie Watchlist Organizer is a Java desktop application that allows users to maintain a list of movies.

The application provides a graphical interface where users can:

- Add movies to the watchlist
- Delete movies from the watchlist
- Display all stored movies
- Sort movies alphabetically
- View movies using a HashSet
- View movies using a TreeSet
- Remove duplicate movie titles using HashSet
- Display movies in sorted order using TreeSet

The project is designed to demonstrate how different Java Collections can be used for different purposes.

## Objectives

The main objectives of this project are:

1. Understand the use of `ArrayList`.
2. Understand how `HashSet` handles duplicate values.
3. Understand how `TreeSet` stores values in sorted order.
4. Practice sorting collections using `Collections.sort()`.
5. Build a basic graphical user interface using Java Swing.
6. Handle user actions using button event listeners.
7. Practice adding and removing data from collections.
