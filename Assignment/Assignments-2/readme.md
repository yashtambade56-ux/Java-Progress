# Assignment 2 - Student Activity Management System

## Java Fundamentals

A simple Java program that implements a **Student Activity Management System** using a menu-driven approach.

---

## Assignment Details

This project is part of the **Java Fundamentals** assignment.

The program allows users to:

- Check Attendance Eligibility
- View Performance Category
- Exit the Program

The program demonstrates basic Java concepts such as:

- Variables and Data Types
- User Input using `Scanner`
- Conditional Statements
- `if-else`
- `switch` Statement
- `while` Loop
- Menu-Driven Program

---

# Features

## Check Attendance Eligibility

The user enters their attendance percentage.

- Attendance greater than 75% → Eligible
- Attendance 75% or below → Not Eligible

---

## View Performance Category

The user enters their marks and the program displays the performance category.

| Marks | Category |
|---|---|
| 90 - 100 | Excellent |
| 70 - 89 | Good |
| 60 - 69 | Average |
| Below 60 | Needs Improvement |

---

## Exit Program

The user can select option `3` to exit the program.
