# Assignment 3 - Food Delivery Partner Rating Analysis

## Java Fundamentals

A simple Java program that analyzes ratings of food delivery partners based on multiple parameters.

---

## Assignment Details

This project is part of the **Java Fundamentals** assignment.

The program analyzes food delivery partners based on four parameters:

- Speed
- Quality
- Packaging
- Service

The program calculates the total and average rating of each partner, searches for a specific rating, finds the highest-rated partner, and ranks all partners.

---

# Features

## Partner Ratings

The program stores ratings for five food delivery partners using a **2D Array**.

Each partner is rated based on:

- Speed
- Quality
- Packaging
- Service

---

## Total and Average Rating

The program calculates:

- Total Rating
- Average Rating

for every food delivery partner.

---

## Search Rating

The user can enter a rating to search within the partner rating data.

The program displays the partner(s) where the rating is found.

---

## Highest Rated Partner

The program compares the total ratings of all partners and displays the partner with the highest rating.

---

## Partner Ranking

The program ranks all delivery partners from highest to lowest based on their total rating.
