# Assignment 4 - Student Marks Management System

## Java Fundamentals

A Java program that manages and analyzes marks of students in different subjects.

---

## Assignment Details

This project is part of the **Java Fundamentals** assignment.

The program stores marks of students in a **2D Array** and performs different operations such as:

- Displaying all marks
- Calculating student totals
- Calculating student averages
- Finding the highest scorer
- Finding subject-wise highest marks
- Searching for marks
- Sorting students based on total marks

---

# Features

## Display All Marks

Displays marks of all students in:

- Java
- Python
- DBMS

---

## Calculate Student Total

Calculates the total marks of every student.

---

## Calculate Student Average

Calculates the average marks of every student.

---

## Highest Scores

Finds:

- Overall highest scorer
- Highest marks in Java
- Highest marks in Python
- Highest marks in DBMS

---

## Search Marks

Uses **Linear Search** to find a specific mark in the student records.

---

## Sort Student Totals

Uses **Bubble Sort** to arrange students from highest to lowest total marks.
