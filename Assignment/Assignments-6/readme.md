# Assignment 6 - Vehicle Rental Management System

## Java Object-Oriented Programming

A simple Java program that manages vehicle rentals using **Inheritance and Object-Oriented Programming concepts**.

---

# Assignment Details

This project is part of the **Java Object-Oriented Programming** assignment.

The program creates a parent `Vehicle` class and different child classes for various vehicle types.

---

# Features

## Vehicle Types

The system supports:

- Car
- Bike
- Scooter
- Electric Car

---

# Vehicle Details

The program stores:

- Vehicle Number
- Vehicle Model
- Customer Name
- Rent Days

For Electric Cars:

- Battery Capacity

---

# Rental Operations

The user can:

- Rent a Car
- Rent a Bike
- Rent a Scooter
- Rent an Electric Car
- Display Vehicle Details
- Calculate Rental Charges
- Exit the Program

---

# Rental Rates
