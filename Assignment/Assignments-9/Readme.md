# Assignment 9: Student Record File Manager

## Overview

The **Student Record File Manager** is a Java console application that demonstrates **File Handling in Java**.

The program creates a directory and record file, writes student records, reads file content, appends new records, displays file information, and deletes the file using a menu-driven program.

---

## Concepts Covered

- `File` class
- Directory creation using `mkdir()`
- File creation using `createNewFile()`
- File information methods
- `FileInputStream`
- `FileOutputStream`
- Reading files
- Writing files
- Appending records
- Deleting files
- Exception handling using `try-catch`
- Menu-driven program
- `Scanner`
- `do-while` loop
